# TUKA Game System OTA

ESP32 TUKA Game System için OTA güncelleme deposu.

## Dosyalar

- `version.json` — cihazın kontrol ettiği sürüm manifesti
- `firmware/TUKA_GameSystem_latest.bin` — sonraki sürümlerde OTA firmware dosyası

Mevcut başlangıç sürümü: **v1.11 / build 111**

> İlk kurulumda firmware dosyası henüz gerekli değil. Cihazdaki build de 111 olduğu için
> güncelleme kontrolü `SİSTEM GÜNCEL` gösterecek.
